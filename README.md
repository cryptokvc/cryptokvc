# cryptokvc

Recherche et documentation technique sur les protocoles blockchain, les preuves zero-knowledge et les infrastructures EVM.
Je transforme la lecture du code source en parcours francophones structurés : architecture, invariants, frontières de confiance et limites opérationnelles.

## Domaines

- **Zero-knowledge** — zkVM, STARK, FRI, récursion, SNARK et vérification EVM.
- **Confidentialité** — FHEVM, calcul sur chiffrés, ACL et déchiffrement autorisé.
- **Base L2** — dérivation depuis Ethereum, exécution, finalité et Flashblocks.
- **Hyperliquid / HyperEVM** — données de marché, ordres, signatures et séparation Core/EVM.
- **EVM et DeFi** — contrats, intégrations et analyse défensive des flux applicatifs.

## Méthode de contribution

Chaque mécanisme est publié dans un chapitre autonome et un commit traçable. Les affirmations restent reliées au code et aux tests du dépôt ; aucune documentation ne prétend remplacer un audit ou certifier un déploiement.
