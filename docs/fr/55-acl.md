# 55. ACL de déchiffrement

Ce chapitre documente lier identité, permission, durée et résultat à partir de GUIDE-FHEVM.md, dans le parcours francophone de cryptokvc. La lecture sépare les faits observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les références restent rattachées au fichier indiqué afin de rendre la relecture vérifiable.

## Limite

une ACL trop large devient une autorité permanente. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
