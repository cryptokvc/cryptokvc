# 28. Binding des entrées publiques

Ce chapitre documente lier entrée publique, preuve et contexte à partir de prototype/zk_public_input_binding.py, dans le parcours francophone de cryptokvc. La lecture sépare les faits observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les références restent rattachées au fichier indiqué afin de rendre la relecture vérifiable.

## Limite

une preuve ne doit pas être détachée de son input. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
