# 42. Erreurs de preuve

Ce chapitre documente distinguer preuve invalide, instance invalide et vérificateur à partir de GUIDE-ZK-FHE.md, dans le parcours francophone de cryptokvc. La lecture sépare les faits observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les références restent rattachées au fichier indiqué afin de rendre la relecture vérifiable.

## Limite

un échec de preuve ne décrit pas toujours sa cause. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
