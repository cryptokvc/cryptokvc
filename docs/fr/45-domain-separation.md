# 45. Séparation de domaines

Ce chapitre documente inclure protocole, chaîne et intention à partir de GUIDE-SIGNATURES-EVM.md, dans le parcours francophone de cryptokvc. La lecture sépare les faits observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les références restent rattachées au fichier indiqué afin de rendre la relecture vérifiable.

## Limite

la réutilisation inter-domaines rend une signature ambiguë. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
