# 31. Acteurs et capacités

Ce chapitre documente distinguer utilisateur, RPC, relais et opérateur à partir de docs/THREAT-MATRIX.md, dans le parcours francophone de cryptokvc. La lecture sépare les faits observables, les hypothèses et les conséquences possibles.

## Repères

La revue suit les entrées, les contrôles, l’état produit et les dépendances externes. Les références restent rattachées au fichier indiqué afin de rendre la relecture vérifiable.

## Limite

une capacité supposée doit être justifiée. Aucun test, audit ou déploiement n’est déclaré dans ce chapitre.
